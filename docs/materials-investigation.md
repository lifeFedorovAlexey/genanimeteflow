# Материалы: исследование треугольных пятен, 2026-09-22

## Источники и сверка реализации

- [Tencent Paint pipeline](https://github.com/Tencent-Hunyuan/Hunyuan3D-2/blob/main/hy3dgen/texgen/pipelines.py): delight → UV → normal/position renders → multiview diffusion → weighted projection → inpaint → export. Штатный размер render/atlas — 2048.
- [Kijai Hunyuan wrapper](https://github.com/kijai/ComfyUI-Hunyuan3DWrapper): отдельное предупреждение и процедура обновления xatlas для плотных сеток. Ноды разделяют UV, bake, vertex inpaint и image inpaint.
- [xatlas PR 141](https://github.com/jpcy/xatlas/pull/141): автор описывает проблему маленьких UV-патчей на high-poly. Это подтверждает известный класс проблемы, но не доказывает применимость конкретного незамерженного патча к нашей сборке.
- [Windows integration report](https://github.com/Tencent-Hunyuan/Hunyuan3D-2/issues/362): предлагается Blender UV вместо xatlas; сам автор ограничивает проверку одним примером. Решение не принималось без проверки нашего персонажа.
- [Tencent postprocessors](https://github.com/Tencent-Hunyuan/Hunyuan3D-2/blob/main/hy3dgen/shapegen/postprocessors.py): удаление мелких отделённых компонентов и вырожденных граней перед дальнейшей обработкой; FaceReducer доступен отдельно.

## Установлено на пользовательском персонаже

Job: `2d0eff02-c40f-47eb-a6d1-e4028ddf8b1b`, четыре пользовательских референса.

1. Исходная форма: 436332 треугольника. Сохранённые картинки шести камер Paint не содержат россыпи треугольных пятен, видимых на GLB. Следовательно, это не основание требовать новые референсы или заменять генеративную модель.
2. Исходная xatlas 0.0.11 развёртка: 21536 компонентов, в том числе 7483 однотреугольных. На старом атласе 1024 около 36.3% треугольников занимали меньше пикселя.
3. Увеличение обычного bake до 2048 уменьшило мелкие дефекты, но не убрало крупные пятна на плече. Простая Blender Smart UV улучшила кожу, оставив белые точки в волосах. Один лишь переход к 4096 не устранил их.
4. Фильтрация atlas без учёта UV-островов не является исправлением. Удалена из production вместе с тихой подменой упавшего Paint на непроверенную vertex-color проекцию.
5. В старом экспортированном GLB отсутствовал `metallicFactor`; стандартное значение glTF — 1. Отсюда неверное металлическое/чёрное отображение кожи. Paint генерирует базовый цвет, не предсказывает полноценные PBR-карты.

## Исправленный путь

Blender weld с минимальным допуском и удаление вырожденных граней → удаление отделённых компонентов меньше 0.5% крупнейшего (по аналогии с Tencent FloaterRemover) → Smart UV для начальных швов → присоединение микроскопических островов к соседним → Angle Based unwrap и pack с отступами → официальный Hunyuan delight/multiview/weighted bake 2048 → заполнение ненаблюдаемых texels по ближайшим наблюдаемым точкам 3D-поверхности → защитное расширение цвета за UV-границы → GLB с явным metallic=0, roughness=0.8.

Развёртка и surface-fill — адаптация проекта, **не выдаются за неизменённый официальный Tencent код**. Для сравнения использованы одни и те же сохранённые изображения камер; повторная диффузия для каждого эксперимента не нужна. Принятая основная форма не decimate'ится: после очистки остаётся 433550 граней; исходный geometry GLB не изменяется. Сглаженные нормали экспортируются непрерывно через UV-швы.

## Проверка и пределы

`scripts/inspect_material_bake.py` сохраняет реальные промежуточные изображения. `scripts/rebake_material_views.py` позволяет сравнивать способы bake на одинаковых входах. `scripts/render_material_review.py` рендерит GLB целиком, плечо и лицо с неизменными камерами: отдельно базовый цвет и освещённый материал.

Обязателен повторный production-run через API и просмотр его GLB в интерфейсе. Unit-тесты проверяют только программные инварианты и **не доказывают визуальное качество**. Устранение точек не равно достижению Tripo/Mixamo или завершению ТЗ. На границе волос и лица остаётся ограниченная точность совмещения с синтезированными видами; nearest-surface fill может ошибаться у очень близко расположенных поверхностей. Это проверяется визуально, а не скрывается фильтром.
